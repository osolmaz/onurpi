# Pi Workflows

This private OnurPi package loads a pinned Pi Workflows commit. It provides the `/workflow` command,
the model-visible `workflow` control tool, workflow run integration, and the built-in `monitor`
workflow. You can ask the agent to monitor or check something at a regular interval. The agent can
start and manage the monitor without requiring you to write workflow JSON.

OnurPi loads this wrapper from the local checkout. It is not published to npm.

Run `/reload` after changing the package or global settings.
